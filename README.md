# Unified Cashback Search

A static web application that searches for coupons and cashback offers across multiple Romanian services including Mastercard Premium Collection, CashClub, and Guerrilla Radio Avanpost.

## Features

- 🔍 **Unified Search**: Search across multiple cashback and coupon platforms
- 🏪 **Multiple Sources**: Integrates with Mastercard Premium Collection, CashClub, and Guerrilla Radio
- ⚡ **Fast Client-Side Search**: Uses Fuse.js for instant fuzzy search
- 📱 **Responsive Design**: Works on desktop and mobile
- 🆓 **Free Hosting**: Designed for GitHub Pages (zero cost, no billing surprises)

## Architecture

## Quick Start

### 1. Install Dependencies

```bash
npm install
npx playwright install chromium
```

### 2. Run Scrapers (populates data)

```bash
npm run scrape
```

This creates/updates `docs/data/offers.json` with all scraped offers.

### 3. Test Locally

```bash
npm run serve
```

Open http://localhost:8888 in your browser.

### 4. Deploy to GitHub Pages

1. Push your code to GitHub
2. Go to your repo's **Settings > Pages**
3. Under "Source", select:
   - Branch: `main`
   - Folder: `/docs`
4. Click **Save**

Your site will be live at `https://YOUR_USERNAME.github.io/YOUR_REPO/`

## Usage

### Scraping Commands

```bash
# Run all scrapers
npm run scrape

# Run individual scrapers
npm run scrape:mastercard
npm run scrape:cashclub
npm run scrape:guerrilla
```

### Updating Data (every 3 days or as needed)

```bash
npm run scrape
git add docs/data/offers.json
git commit -m "Update offers $(date +%Y-%m-%d)"
git push
```

GitHub Pages will auto-deploy within seconds.

## Optional: Automated Scraping with launchd (macOS)

To automatically run scrapers every 3 days:

1. Create `~/Library/LaunchAgents/com.cashback.scraper.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.cashback.scraper</string>
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>-c</string>
        <string>cd /PATH/TO/YOUR/PROJECT && npm run scrape && git add docs/data && git diff --cached --quiet || git commit -m "Auto-update offers" && git push</string>
    </array>
    <key>StartInterval</key>
    <integer>259200</integer> <!-- 3 days in seconds -->
    <key>RunAtLoad</key>
    <true/>
</dict>
</plist>
```

2. Load it:

```bash
launchctl load ~/Library/LaunchAgents/com.cashback.scraper.plist
```

## Development

### Adding New Scrapers

1. Create a new scraper file in `scrapers/`
2. Implement a `scrape()` method that returns an array of offers:

```javascript
{
  name: "Merchant Name",
  source: "scraper-key",
  url: "https://...",
  offers: [
    { description: "Offer description", cashback: "5%" }
  ]
}
```

3. Add the scraper to `scrapers/run-scrapers.js`
